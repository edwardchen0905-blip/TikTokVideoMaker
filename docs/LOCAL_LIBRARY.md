# 本地资料使用与边界

同一个 workspace.sqlite3 保存商品、素材、音乐、任务和本地资料。无第二套数据库、播放器或队列。软件内“本地资料库”支持创建、搜索、编辑、导入JSON/CSV、导出和删除；更新使用ID、版本及匹配身份校验，冲突行不覆盖。

首次启动内置6条文本记录：泰文和英文各2套通用文本、1套中性关键词模板，每套有标题、Caption、Hashtag、开头、CTA、封面文字6个用途。内置只初始化不存在的记录，更新软件不覆盖用户编辑或恢复用户删除记录。关键词模板只插入本次可靠且具有对应语言表达的关键词。

正式图名、材质、颜色、已有关键词、音乐标签对应关系和歌曲均未预置，不用验收资料冒充用户资料。测试文件只在自动验收临时目录使用，不进入便携包。

创建任务默认使用简单模式：选择商品或素材、生成视频数量、转场效果、视频尺寸、文案语言和音乐方式即可开始。高级设置默认折叠，可调整素材组合、顺序、逐图或总时长、音量、关键词来源、文本池与输出目录。默认本地素材合为一组，商品分别生成；分别生成时每个所选对象至少分配一条视频，增加的数量按所选对象顺序轮换，不混用不同商品素材。

“转场效果”只决定图片之间如何切换，不是整套生产方案。支持直接切换、淡入淡出、溶解、四向滑动、推入和安全缩放切换；多选时按勾选顺序循环。效果预览是同一渲染引擎生成的示意视频。旧生产模板不再用于新任务，历史记录保留原配置并可查看或重新生成。

视频尺寸支持竖屏9:16、方形1:1、横屏16:9，默认竖屏1080×1920。图片始终等比例完整显示，空余位置留白，不裁切或拉伸；方形图片在竖屏画布中通常上下留白。选择总时长与逐图时长冲突时会明确提示，不静默覆盖。

创建任务时选择语言，高级设置中可选择关键词来源、已有关键词与文本池。未勾选来源不提供文字；其他商品资料的明确否定只用于否决错误断言，不会补入未勾选文字。SKU仅在明确三段时解析；图名中的多个分隔符导致无法确定时记录未匹配。词典匹配使用实际别名，不自动猜测、翻译或扩展属性。商品标题/详情只提取词典中已有的确认表达，未知词汇用对应语言通用文本兜底。

多商品及多SKU任务仅使用各对象共有且无冲突的关键词。已有视频标题可以检索已有关键词并记录来源，但不作为商品事实生成新断言。功能词不能从材质、颜色或图名推测；功能表达需本次商品标题/详情证据。否定检查保守处理整句；不是自然语言理解服务，也不保证平台审核或权利许可。

本地自动匹配只用关键词标签、音乐标签及资料库中可维护的标签对应关系。无匹配时预览明确显示，执行要求改为单曲、多曲、无音乐或补齐资料，不暗中调用AI。随机方式为池内打乱，尽量避免跨轮相邻重复。

任务保存资料版本、原SKU、证据、未匹配/省略原因、实际文本、兜底情况、音乐ID/元数据/匹配规则快照。视频详情读取这些快照；修改本地库不改变历史，重新生成沿用原任务配置。开头和封面文字仅作为发布文字保存，不强制画到视频上。

中文目前仅预留且禁用；泰英可运行。AI增强、TikTok同步/下载/上传/发布、Pixabay自动搜索下载均等待真实接入。离线能力只指本地资料、文案、音乐和渲染生产链。
